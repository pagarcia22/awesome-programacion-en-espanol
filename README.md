# Awesome Programación en Español [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> Una lista curada de los mejores recursos **gratuitos** para aprender programación **en español**: documentación, cursos, canales, libros y retos.

Aprender a programar ya es difícil; hacerlo en un idioma que no dominas lo es más. Esta lista reúne recursos de calidad en español para que cualquier persona hispanohablante pueda empezar (o avanzar) sin barreras.

⭐ **Si te sirve, dale una estrella** — ayuda a que más gente la encuentre.

## Documentación oficial

- [MDN Web Docs](https://developer.mozilla.org/es/) - Referencia completa de HTML, CSS y JavaScript.
- [Documentación de Python](https://docs.python.org/es/3/) - Traducción oficial del tutorial y la referencia de Python.
- [React](https://es.react.dev/) - Documentación oficial de React en español.
- [Pro Git](https://git-scm.com/book/es/v2) - El libro oficial de Git, gratis y traducido.

## Cursos gratuitos

- [freeCodeCamp en español](https://www.freecodecamp.org/espanol/) - Currículo interactivo con certificaciones gratuitas.
- [Aprende Python](https://aprendepython.es/) - Curso completo de Python desde cero, de Sergio Delgado Quintero.
- [JavaScript.info](https://es.javascript.info/) - Tutorial moderno de JavaScript, desde lo básico hasta temas avanzados.

## Canales de YouTube

- [MoureDev](https://www.youtube.com/@mouredev) - Cursos completos de Python, Git, Swift y más.
- [midudev](https://www.youtube.com/@midudev) - Desarrollo web, JavaScript y React.
- [HolaMundo](https://www.youtube.com/@HolaMundoDev) - Cursos de programación claros y directos.
- [Fazt](https://www.youtube.com/@FaztCode) - Tutoriales prácticos de desarrollo web y backend.
- [FalconMasters](https://www.youtube.com/@falconmasters) - Diseño y desarrollo web.
- [EDteam](https://www.youtube.com/@EDteam) - Conceptos de programación y tecnología explicados.
- [Dot CSV](https://www.youtube.com/@DotCSV) - Inteligencia artificial y machine learning.

## Libros

- [JavaScript Elocuente](https://eloquentjs-es.thedojo.mx/) - Traducción del clásico *Eloquent JavaScript*.
- [Pro Git](https://git-scm.com/book/es/v2) - Todo sobre control de versiones con Git.

## Repositorios para aprender

- [mouredev/Hello-Python](https://github.com/mouredev/Hello-Python) - Curso de Python desde cero con código de ejemplo.
- [midudev/aprendiendo-react](https://github.com/midudev/aprendiendo-react) - Proyectos y ejercicios para aprender React.

## Retos y práctica

- [AdventJS](https://adventjs.dev/es) - Retos de JavaScript y TypeScript cada diciembre.

## Contribuir

¡Las contribuciones son bienvenidas! Lee la [guía de contribución](CONTRIBUTING.md) antes de abrir un *pull request*.

Criterios rápidos:
- El recurso debe estar **en español** (o tener traducción completa).
- Debe ser **gratuito** o tener una parte gratuita sustancial.
- Debe estar **activo y ser de calidad**.
